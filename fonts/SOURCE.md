# Font

`ibm-plex-sans-latin-wght-normal.woff2` is the Latin subset of the IBM Plex Sans
variable font (weight axis 100–700), taken from
[`@fontsource-variable/ibm-plex-sans`](https://www.npmjs.com/package/@fontsource-variable/ibm-plex-sans).

IBM Plex Sans is licensed under the SIL Open Font License 1.1. That licence
covers this file and travels with it; it is not affected by this repository's
Apache-2.0 or CC-BY-4.0 licences, which cover our code and our specification
text respectively.

Self-hosted deliberately: no third-party request is made when the page loads,
which is what lets the page claim that nothing leaves it.
